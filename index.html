The problem

Deployed models degrade silently

Once a model is in production, the appearance of incoming data changes: different capture devices, resolutions, compression settings and acquisition conditions. The model raises no error and its output looks entirely normal, while accuracy quietly falls.

01A model is trained, validated and deployed
02The distribution of incoming data drifts
03Accuracy falls, but nothing is raised
04Measuring the loss requires labeled data
05Production data is unlabeled — so the degradation stays invisible

The approach

Accuracy cannot be measured in production, but the input always can

What is missing is not the data — it is knowing how much a given change in the input costs in accuracy. DriftWatch builds that mapping in the lab, then applies it in the field.

Stage 1 — Lab

Controlled degradation benchmark

Each degradation factor — noise, blur, JPEG compression, resolution loss, contrast shift, geometric distortion — is applied in isolation at graded severity levels to a labeled test set. Content is preserved, so the ground truth stays valid and no new annotation is needed.

→ accuracy–severity curve per factor

Stage 2 — Field

Label-free drift detection

The same image quality and statistical features are extracted from incoming data and compared against a reference distribution using Kolmogorov–Smirnov, Wasserstein distance and MMD — without labels, and without running the model.

→ predicted accuracy loss + early warning

Standard drift metrics measure how much an input changed. They do not measure how much that change mattered. DriftWatch weights each signal by the accuracy cost measured for it.

Research questions

What the study actually tests

RQ1Which degradation factors contribute most to accuracy loss, and how does this sensitivity differ across models?
RQ2To what extent do standard drift metrics correlate with actual accuracy loss?
RQ3Does an impact-weighted drift score predict degradation better than an unweighted one?

Evaluation uses Spearman correlation between drift score and accuracy loss, AUROC for early-warning performance, and detection delay — how many severity levels before accuracy crosses a threshold the alarm fires.
