Abstract

Seeing a model fail before anyone labels the data

Once a deep learning model is deployed, the appearance of the data reaching it changes over time: different capture devices, resolutions, compression settings and acquisition conditions. The model keeps producing normal-looking output and raises no errors, yet its accuracy quietly declines. Measuring that decline normally requires labels, which production data does not have.

DriftWatch connects two things that are usually studied apart. A controlled degradation benchmark measures, factor by factor, how much each kind of input change costs in accuracy. A label-free drift detector then measures the same factors in incoming data. Weighting drift signals by their measured cost aims to turn “the input changed” into “the model is likely losing accuracy.”

The problem

Deployed models degrade silently

The model raises no error and its output looks entirely normal, while accuracy quietly falls. Teams are left to wait for a user complaint or pay for regular annotation.

The approach

Accuracy can't be measured in production, but the input always can

What is missing is not the data — it is knowing how much a given change in the input costs in accuracy. DriftWatch builds that mapping in the lab, then applies it in the field.

Stage 1 · Lab

Controlled degradation benchmark

Noise, blur, JPEG compression, resolution loss, contrast shift and geometric distortion are each applied in isolation, at graded severity, to a labeled test set. Content is preserved, so the ground truth stays valid and no new annotation is needed.

→ an accuracy–severity curve per factor

Stage 2 · Field

Label-free drift detection

The same image quality and statistical features are extracted from incoming data and compared with a reference distribution using Kolmogorov–Smirnov, Wasserstein distance and MMD — without labels, and without running the model.

→ predicted accuracy loss and an early warning

Standard drift metrics measure how much an input changed. They do not measure how much that change mattered. DriftWatch weights each signal by the accuracy cost measured for it.

Expected contribution

Three outputs, each useful on its own

Factor-resolved benchmark

A reusable degradation benchmark for comparing the robustness of new models, factor by factor.

Performance-aligned evaluation

An evaluation of drift detectors by whether the shift they flag actually harms the task — a step current work omits.

Impact-weighted drift score

A drift score that combines the two, weighting each signal by the accuracy cost measured for it.

A negative result for the weighting is itself reportable, since the alignment measurement stands independently.
